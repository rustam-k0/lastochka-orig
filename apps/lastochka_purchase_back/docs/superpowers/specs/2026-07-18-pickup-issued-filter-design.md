# Фильтр «Выдан» на странице заказов АП (самовывоз)

Дата: 2026-07-18. Задача: АП → Заказы → добавить статус «Выдан» в фильтр и таблицу заказов для заказов, оформленных самовывозом.

## Контекст

«Выдан» — не отдельный статус в БД. Это `ORDER_FINISHED (status_id=5)` у заказа с `type_id=1` (самовывоз); проставляется мутацией `OrderPickupConfirm`. Таблица заказов (`orders/index.vue`) и карточка заказа (`OrderPageAside.vue`) уже отображают «Выдан» по этому условию. Не хватает опции в фильтре статусов.

## Решение: виртуальный код статуса в фильтре

Фронт шлёт в существующий аргумент `statuses:[Int]` виртуальный код `7`; бэкенд разворачивает его в условие по двум колонкам. БД, события RabbitMQ, другие сервисы не затрагиваются.

### Семантика (утверждена)

| Выбрано в фильтре | Условие выборки |
|---|---|
| «Выдан» (7) | `status_id = 5 AND type_id = 1` |
| «Доставлен» (5) | `status_id = 5 AND (type_id != 1 OR type_id IS NULL)` |
| Оба (5 и 7) | `status_id = 5` (все завершённые) |
| Прочие коды (1,2,3,4,6) | `whereIn('status_id', ...)` как раньше |

Опции фильтра не пересекаются и 1:1 совпадают с бейджами в таблице. Смешанные наборы (например `[1,7]`) объединяются через OR внутри одной группы `where(function)`, чтобы не ломать остальные фильтры (тип, оплата, суммы, даты).

## Изменения

### mendev_purchase_back (ветка `feature/pickup-issued-filter`)

1. `app/Filters/OrderFilter.php` → `statuses()`:
   - `const FILTER_ISSUED = 7` — виртуальный код фильтра, в таблице `statuses` не существует;
   - выделить из входного массива коды 5 и 7; оба → 5 уходит в общий `whereIn`; только один → соответствующая OR-ветка по таблице выше; остальные коды → `whereIn`.
2. `graphql/Purchase/Order/OrderQueries.graphql` — докстрока к `statuses`: описать коды, включая виртуальный 7.
3. Тесты (PHPUnit, только локально, локальная БД): фильтр `[7]`, `[5]`, `[5,7]`, `[1,7]`, без фильтра; проверка, что выданный самовывоз попадает/не попадает в выборку согласно таблице семантики.

### mendev_admin_front (ветка `feature/pickup-issued-filter`)

1. `src/views/orders/components/OrdersPageFilters.vue` → `STATUS_OPTIONS`: добавить `{ id: 7, title: "Выдан" }` после «Доставлен». Мультиселект и URL-персист generic — других правок не нужно.
2. `src/views/orders/open.vue` → `orderStatusLabel()`: для бейджа подзаказа при `page.type_id === 1` статус 5 показывать «Выдан» (консистентность с таблицей).
3. Таблица заказов — без изменений (уже готова).

## Вне scope

- Таблица заказов в карточке клиента (`ClientOrdersComponent.vue`, раздел «Клиенты» — свой фильтр).
- Синхронизация на другие форки (sync-core по отдельной команде).
- Реальный статус «Выдан» в БД / событиях (целевой рефакторинг не требуется).

## Деплой и верификация

Merge `--no-ff` в master обоих репо по явной команде → автодеплой CI (`last_pipeline --wait`) → ручная проверка фильтра на dev (`https://raz-dev.mendev.ru/admin`, страница «Заказы»): опция «Выдан» показывает только выданные самовывозы, «Доставлен» — только доставленные, оба — все завершённые.
