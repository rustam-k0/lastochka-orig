# Форма обратной связи (MENDEV-6)

Контракт новой ручки storefront для мобилки. Обращение уходит письмом на почту заказчика через очередь; в базе не сохраняется. Не задеплоено (ждёт пуша).

## Что предоставляется

Новая публичная ручка `POST /api/v1/feedback` — отправка обращения из формы обратной связи.

## База

| | |
|---|---|
| Endpoint | `POST /api/v1/feedback` |
| Dev | `https://store.raz-dev.mendev.ru` |
| Auth | не требуется; Bearer принимается (согласие фиксируется за пользователем) |
| Content-Type | `application/json` |
| Rate limit | 5 обращений в час с одного IP → далее 429 |

## Ручка

### POST /api/v1/feedback

| Поле | Тип | Обяз. | Описание | Ограничения |
|---|---|---|---|---|
| name | string | да | Имя отправителя | max 255 |
| phone | string | нет | Контактный телефон | max 32, формат не валидируется, допускается `null` |
| email | string | нет | Почта для ответа; попадает в reply-to письма | валидный email, max 255, допускается `null` |
| message | string | да | Текст обращения | max 5000 |
| personalDataConsent | boolean | да | Согласие на обработку перс. данных | принимаются только truthy-значения (`true`, `1`, `"yes"`, `"on"`) |

Ответ `200`: `{"message": "Обращение успешно отправлено"}`.

Согласие на обработку перс. данных фиксируется сервером в журнале согласий (с IP и контактами из формы; для запроса с Bearer — за пользователем).

## Коды ответов

| Ситуация | HTTP | Тело |
|---|---|---|
| Успех | 200 | `{"message": "Обращение успешно отправлено"}` |
| Нет обязательного поля / consent не дан / email невалиден / message > 5000 | 422 | `{"message": "...", "errors": {"<поле>": [...]}}` |
| Больше 5 обращений в час с IP | 429 | стандартный ответ throttle |

## Пример

```bash
curl -X POST 'https://store.raz-dev.mendev.ru/api/v1/feedback' \
  -H 'Content-Type: application/json' \
  -d '{"name":"Иван Иванов","phone":"+7 999 123-45-67","email":"ivan@example.com","message":"Не пришёл чек по заказу №123","personalDataConsent":true}'
```

```json
{"message": "Обращение успешно отправлено"}
```

## Обратная совместимость

Ручка новая, существующие не менялись.
