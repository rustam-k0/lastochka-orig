# Ручка текущего IP клиента (MENDEV-18)

Контракт новой ручки storefront для мобилки. Не задеплоено (ждёт пуша).

## Что предоставляется

Новая публичная ручка `GET /api/v1/client-ip` — внешний IP, с которого пришёл запрос.

## База

| | |
|---|---|
| Endpoint | `GET /api/v1/client-ip` |
| Dev | `https://store.raz-dev.mendev.ru` |
| Auth | не требуется |
| Rate limit | нет |

## Ручка

### GET /api/v1/client-ip

Параметров нет. Ответ `200`:

```json
{"data": {"ip": "203.0.113.5"}}
```

`ip` — строка, всегда присутствует. Сервер стоит за прокси и определяет адрес по первому элементу `X-Forwarded-For`; формат — IPv4 или IPv6 в зависимости от подключения клиента.

## Пример

```bash
curl 'https://store.raz-dev.mendev.ru/api/v1/client-ip'
```

## Обратная совместимость

Ручка новая, существующие не менялись.
