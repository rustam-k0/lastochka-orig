# Добавки (Supplements) — интеграция для мобильного приложения

> **Дата:** 2026-03-13
> **Версия API:** v1
> **Figma:** [Макет экрана товара с добавками](https://www.figma.com/design/M7usrkihkveQxUM8mllIPI/?node-id=1395:16278)

---

## 1. Общая концепция

У товаров появились **добавки** (supplements) — группы опций, которые покупатель выбирает на экране товара перед добавлением в корзину.

Каждая добавка имеет:
- **`type: "one"`** — одиночный выбор (radio), можно выбрать ровно 1 значение
- **`type: "many"`** — множественный выбор (checkbox), можно выбрать 1+ значений
- **`isRequired: true`** — обязательная добавка (нельзя добавить товар без выбора)

Каждое значение добавки может иметь **цену** (доплата). Цена 0 — бесплатная опция.

### Флаг `hasSupplements` в списках товаров

В списках (каталог, поиск, акции, избранное, товарные группы) у каждого товара приходит поле **`hasSupplements: bool`**. Если `true` — товар имеет добавки и при нажатии «В корзину» нужно перенаправить пользователя на детальную карточку товара для выбора добавок, а не добавлять мгновенно.

## 2. UI по дизайну (Figma)

На экране товара (детальная карточка) после описания и КБЖУ отображаются блоки добавок:

### Тип `one` (радиокнопки)
```
Соус на выбор: *                    ← заголовок + * если isRequired
◉ Сырный                            ← выбран по умолчанию (первый)
○ Кетчуп
○ Горчица
```

### Тип `many` (чекбоксы)
```
Допы:                                ← заголовок
☑ Аджика                    +50 ₽   ← цена справа, цвет #F8623F
☑ Сметана с чесноком        +40 ₽
☐ Чесночно-томатная         +30 ₽
```

### Нижняя панель (кнопка «В корзину»)
Цена на кнопке пересчитывается в реальном времени:
```
[  1  -  +  ]          260 ₽  В корзину
```
`260 = 170 (товар) + 50 (Аджика) + 40 (Сметана)`

**Формула для кнопки:**
```
buttonPrice = (product.price + sum(selectedValues.price)) * quantity
```

## 3. API-контракты

### 3.0. Товар в списках — `hasSupplements`

Во всех эндпоинтах, возвращающих списки товаров, у каждого товара теперь есть поле `hasSupplements`:

```json
{
  "id": 42,
  "title": "Борщ, 300 г",
  "price": 170,
  ...
  "hasSupplements": true
}
```

| Поле | Тип | Описание |
|---|---|---|
| `hasSupplements` | bool | `true` если у товара есть добавки. При нажатии «В корзину» — перенаправить на детальную карточку |

Поле приходит в:
- `GET /stores/{store}/categories` (товары в категориях)
- `GET /products/{id}/similar` (похожие товары)
- `GET /search/products` (поиск по всем магазинам)
- `GET /search/stores/{store}/products` (поиск в конкретном магазине)
- `GET /promotions/{id}/products` (товары акции)
- `GET /favorites` (избранное)
- `GET /product-groups/{id}/products` (товары группы)
- `GET /product-groups` и `GET /stores/{store}/product-groups` (товары внутри групп)

### 3.1. Получение товара — `GET /api/v1/products/{id}`

Поле `supplements` теперь приходит на детальной карточке товара.

**Новое поле в ответе:**
```json
{
  "id": 42,
  "title": "Борщ, 300 г",
  "price": 170,
  "priceOld": null,
  "discountPercent": null,
  ...
  "supplements": [
    {
      "id": 1,
      "title": "Соус на выбор",
      "type": "one",
      "isRequired": true,
      "values": [
        { "id": 10, "title": "Сырный", "price": 0 },
        { "id": 11, "title": "Кетчуп", "price": 0 },
        { "id": 12, "title": "Горчица", "price": 0 }
      ]
    },
    {
      "id": 2,
      "title": "Допы",
      "type": "many",
      "isRequired": false,
      "values": [
        { "id": 20, "title": "Аджика", "price": 50 },
        { "id": 21, "title": "Сметана с чесноком", "price": 40 },
        { "id": 22, "title": "Чесночно-томатная", "price": 30 }
      ]
    }
  ]
}
```

**Важно:**
- Если у товара нет добавок, `supplements` — пустой массив `[]`
- В списке товаров (каталог, поиск) `supplements` **не приходит** — массив `[]`
- Добавки доступны **только** на экране детальной карточки

### 3.2. Добавление в корзину — `POST /api/v1/cart/items`

**Request body:**
```json
{
  "productId": 42,
  "quantity": 1,
  "supplements": [
    {
      "supplementId": 1,
      "values": [10]
    },
    {
      "supplementId": 2,
      "values": [20, 21]
    }
  ]
}
```

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `productId` | int | да | ID товара |
| `quantity` | int | да | Количество (1–99999) |
| `supplements` | array | нет* | Массив выбранных добавок |
| `supplements[].supplementId` | int | да | ID добавки |
| `supplements[].values` | int[] | да | Массив ID выбранных значений (min: 1) |

> \* Поле `supplements` обязательно, если у товара есть добавки с `isRequired: true`. Если не передать — ответ 422.

**Правила валидации:**
- `type: "one"` — массив `values` должен содержать ровно 1 элемент
- `type: "many"` — массив `values` должен содержать 1+ элементов
- Все `supplementId` должны принадлежать данному товару
- Все `values` должны принадлежать своему `supplementId`
- Все добавки с `isRequired: true` должны присутствовать в запросе

**Ответ 200 — корзина (стандартный CartResource).** Внутри `items` теперь есть:
```json
{
  "storeGroups": [
    {
      "items": [
        {
          "id": 15,
          "product": { "id": 42, "title": "Борщ, 300 г", "price": 170, ... },
          "quantity": 1,
          "price": 170,
          "supplements": [
            {
              "supplementId": 1,
              "title": "Соус на выбор",
              "type": "one",
              "values": [
                { "id": 10, "title": "Сырный", "price": 0 }
              ]
            },
            {
              "supplementId": 2,
              "title": "Допы",
              "type": "many",
              "values": [
                { "id": 20, "title": "Аджика", "price": 50 },
                { "id": 21, "title": "Сметана с чесноком", "price": 40 }
              ]
            }
          ],
          "supplementsTotal": 90
        }
      ],
      "discount": 0,
      "deliveryCost": 200,
      ...
    }
  ]
}
```

**Новые поля в CartItem:**

| Поле | Тип | Описание |
|---|---|---|
| `supplements` | array | Массив выбранных добавок для этого CartItem |
| `supplements[].supplementId` | int | ID добавки |
| `supplements[].title` | string | Название группы добавок |
| `supplements[].type` | string | `"one"` или `"many"` |
| `supplements[].values` | array | Выбранные значения |
| `supplements[].values[].id` | int | ID значения |
| `supplements[].values[].title` | string | Название значения |
| `supplements[].values[].price` | int | Цена значения |
| `supplementsTotal` | int | Сумма цен всех добавок × quantity |

**Ответ 422 — ошибки валидации:**
```json
{
  "message": "Не все обязательные добавки выбраны",
  "errors": {
    "supplements": ["Не все обязательные добавки выбраны"]
  }
}
```

Возможные ошибки:
- `"Не все обязательные добавки выбраны"`
- `"Добавка не принадлежит данному товару"`
- `"Для добавки «Соус на выбор» можно выбрать только одно значение"`

### 3.3. Обновление позиции корзины — `PUT /api/v1/cart/items/{cartItem}`

**Request body:**
```json
{
  "quantity": 2,
  "supplements": [
    {
      "supplementId": 1,
      "values": [11]
    }
  ]
}
```

При передаче `supplements` — старые добавки полностью заменяются новыми. Если поле `supplements` не передано — добавки не меняются.

### 3.4. Получение корзины — `GET /api/v1/cart`

Ответ — стандартный CartResource (см. п. 3.2). Все CartItem содержат `supplements` и `supplementsTotal`.

### 3.5. Заказ — `GET /api/v1/orders/{id}`

```json
{
  "data": {
    "id": 100,
    "subtotal": 260,
    ...
    "items": [
      {
        "id": 50,
        "productId": 42,
        "title": "Борщ, 300 г",
        "price": 170,
        "quantity": 1,
        "total": 170,
        ...
        "supplements": [
          {
            "supplementId": 1,
            "title": "Соус на выбор",
            "amount": 0,
            "values": [
              { "id": 10, "title": "Сырный", "amount": 0 }
            ]
          },
          {
            "supplementId": 2,
            "title": "Допы",
            "amount": 90,
            "values": [
              { "id": 20, "title": "Аджика", "amount": 50 },
              { "id": 21, "title": "Сметана с чесноком", "amount": 40 }
            ]
          }
        ]
      }
    ]
  }
}
```

**Отличия от корзины:**
- Вместо `price` у значений — поле `amount` (snapshot цены на момент оформления)
- У группы добавок также `amount` — суммарная цена всех выбранных значений

## 4. Ключевое поведение

### 4.1. Один товар — разные наборы добавок = разные позиции

Если пользователь добавляет один товар дважды с **разными** добавками — в корзине будет **2 отдельных CartItem**:
```
CartItem #1: Борщ × 1 — Сырный соус
CartItem #2: Борщ × 1 — Кетчуп
```

Если добавить тот же товар с **теми же** добавками — **увеличится quantity** существующего CartItem.

### 4.2. Расчёт цен

```
itemTotal = (item.price + supplementsTotal / quantity) * quantity
         = item.price * quantity + supplementsTotal

Где supplementsTotal = sum(всех values.price) * quantity
```

**Пример:**
- Борщ 170₽, qty=2, Аджика +50₽, Сметана +40₽
- `supplementsTotal = (50 + 40) * 2 = 180`
- `itemTotal = 170 * 2 + 180 = 520`

### 4.3. Промокоды

Промокод применяется **только к базовой цене товара**, добавки НЕ участвуют в скидке.

### 4.4. Порог бесплатной доставки

Сумма заказа **с учётом добавок** учитывается при расчёте бесплатной доставки (поле `freeDeliveryFrom`).

## 5. Рекомендации по реализации (Flutter)

### 5.0. Списки товаров (каталог, поиск, и т.д.)

1. Проверить поле `hasSupplements` у каждого товара
2. Если `hasSupplements: true` — при нажатии кнопки «В корзину» вместо мгновенного добавления перенаправить на детальную карточку товара
3. Опционально: визуально отметить товар с добавками (иконка, бейдж)

### 5.1. Экран товара

1. После загрузки `GET /products/{id}` проверить наличие `supplements`
2. Если массив не пустой — отрисовать блоки добавок между описанием и кнопкой
3. Для `type: "one"` — компонент Radio Group, по умолчанию выбран первый
4. Для `type: "many"` — компонент Checkbox Group, по умолчанию ничего не выбрано
5. Если `isRequired: true` — пометить заголовок звёздочкой `*`
6. Цену на кнопке «В корзину» пересчитывать при каждом изменении выбора
7. При `price > 0` у значения — отображать `+{price} ₽` справа (цвет `#F8623F`)

### 5.2. Корзина

1. Под каждым CartItem отображать выбранные добавки (из `supplements`)
2. Показывать `supplementsTotal` отдельной строкой или суммировать с ценой товара
3. В итоговой цене учитывать `supplementsTotal` каждой позиции

### 5.3. Редактирование в корзине

При редактировании количества (`PUT /cart/{id}`) — если не передавать `supplements`, они не изменятся. Для смены добавок передать полный массив `supplements`.

### 5.4. Экран заказа

Аналогично корзине — показывать `supplements` у каждой позиции. Использовать `amount` (snapshot) вместо текущей цены.
