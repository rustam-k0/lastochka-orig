## Навигация (TabBar)

Нижняя навигация присутствует на всех основных экранах:

| Таб | Экран |
|-----|-------|
| Главная | Главная страница |
| Каталог | Каталог категорий |
| Избранное | Избранное |
| Профиль | Профиль пользователя |

Также на всех экранах плавающая панель снизу: **кнопка "Поиск"** и **кнопка корзины** (с суммой, например `500 ₽`).

## 1. Авторизация

**Figma секция:** `Авторизация` (id: `2016:5462`)

### Экраны в дизайне:
1. **Ввод номера телефона** — поле ввода, кнопка "Получить код", ссылки на условия использования и обработку ПД
2. **Ввод SMS-кода** — 6 полей для цифр, таймер повторной отправки ("Получить новый код можно через 00:53")
3. **Успешный ввод кода** — заполненные 6 полей + кнопка "Войти"

### Связь с API:
| Элемент | Статус | API |
|---------|--------|-----|
| Ввод номера | **Связано** | `POST /api/v1/auth/send-otp` |
| Ввод SMS-кода | **Связано** | `POST /api/v1/auth/verify-otp` |
| Таймер повторной отправки | **Фронтенд** | Логика на клиенте, бэкенд ограничивает через rate limiting |
| Ссылки на документы | **Связано** | `GET /api/v1/pages` |

## 2. Главная страница

**Figma секция:** `Главная` (id: `379:2149`)

### Экраны в дизайне:
1. **Шапка** — адрес доставки (например "Кантемиров, д. 26"), иконки уведомлений и профиля
2. **Stories (истории)** — горизонтальная лента кружков
3. **Активный заказ** — мини-карточка заказа ("Заказ собран. Доставим через 40 минут")
4. **Блок "Рекомендуем"** — товарные группы с флагом `is_recommended`
5. **Блок "Успей купить"** — товарная группа (акционные товары с таймером/скидками)
6. **Блок "Новинки"** — товарная группа
7. **Каталог категорий** — сетка категорий: Кулинария, Овощи и фрукты, Молоко/яйца/сыр, Хлеб и выпечка, Мясо и рыба, Мороженое
8. **Блок "Как получить бонусы?"** — попап/модалка с описанием системы лояльности
9. ~~**QR-код бонусов**~~ — **не входит в МВП**

### Связь с API:
| Элемент дизайна | Статус | API |
|-----------------|--------|-----|
| Адрес доставки | **Связано** | `GET /api/v1/addresses`, активный: `GET /api/v1/addresses/active` |
| Stories | **Связано** | `GET /api/v1/stories` |
| Активный заказ | **Связано** | `GET /api/v1/orders/active` |
| Товарные группы "Рекомендуем" | **Связано** | `GET /api/v1/product-groups` (флаг `is_recommended=true`) |
| Товарные группы "На главную" | **Связано** | `GET /api/v1/product-groups` (флаг `show_on_home=true`) |
| Каталог категорий | **Связано** | `GET /api/v1/stores/{store}/categories` |
| Блок бонусов (количество) | **Связано** | Данные из профиля пользователя `GET /api/v1/user` |
| Уведомления (иконка) | **Связано** | Переход на экран уведомлений |

## 3. Каталог / Категории

**Figma секция:** `Категории` (id: `379:2150`)

### Экраны в дизайне:
1. **Каталог** — дерево категорий верхнего уровня с подкатегориями (горизонтальные табы: Кулинария, Кондитерские изделия, etc.), сортировка по подкатегориям
2. **Категория с подкатегориями** — список подкатегорий, блок акций (товары со скидкой), затем секции по подкатегориям (4 товара каждая)
3. **Подкатегория** — сетка товаров (2 колонки), фильтры вверху
4. **Модалка "Выберите формат магазина"** — выбор магазина/точки доставки (список адресов магазинов с радио-кнопками)
5. **Модалка "Новый отзыв"** — форма с звёздочками, тегами, текстовым полем

### Связь с API:
| Элемент дизайна | Статус | API |
|-----------------|--------|-----|
| Дерево категорий | **Связано** | `GET /api/v1/stores/{store}/categories` с `includeChildren=true` |
| Подкатегории | **Связано** | `GET /api/v1/stores/{store}/categories/{category}/children` |
| Товары категории | **Связано** | `GET /api/v1/stores/{store}/categories/{category}/products` |
| Блок акций (товары со скидкой) | **Связано** | Параметр `only_discounted=true` в запросе товаров |
| Фильтры (табы подкатегорий) | **Связано** | Навигация по `category_id` |
| Выбор магазина | **Связано** | `GET /api/v1/stores` |
| Кнопка добавления в корзину | **Связано** | `POST /api/v1/cart/items` |
| Toast при добавлении | **Фронтенд** | Snackbar/toast на клиенте |

| Элемент дизайна | Статус | API |
|-----------------|--------|-----|
| Список уведомлений | **Нет в бэке** | Нет API. Нужна реализация |
