# Приложение B: Настройка обмена на стороне 1С

## Требования

- 1С:Предприятие 8.3 (ваша версия: 8.3.22.1709 ✓)
- Конфигурация с поддержкой обмена с сайтами (Торговое предприятие 7 ✓)
- Доступ к веб-серверу Laravel из сети 1С

---

## Шаг 1: Проверка наличия обработки обмена

1. Откройте 1С
2. Перейдите в **Администрирование** → **Обмен данными**
3. Найдите раздел **Узлы обмена с сайтами** или **Обмен с сайтом**

> В "Торговое предприятие 7" обмен с сайтами обычно уже встроен.

---

## Шаг 2: Создание узла обмена

1. **Администрирование → Обмен данными → Узлы обмена с сайтами**
2. Нажмите **Создать**
3. Заполните параметры:

| Поле | Значение |
|------|----------|
| **Наименование** | Интернет-магазин (или любое понятное имя) |
| **Адрес сайта** | `https://your-domain.com` |
| **Каталог на сайте** | `/1c-exchange` |
| **Имя пользователя** | Логин для авторизации (создайте в Laravel) |
| **Пароль** | Пароль для авторизации |

---

## Шаг 3: Настройка выгрузки каталога

### Выгружаемые данные

Отметьте галочками:
- [x] **Товары** — номенклатура
- [x] **Группы товаров** — категории
- [x] **Свойства товаров** — характеристики
- [x] **Изображения** — фотографии товаров
- [x] **Цены** — выберите типы цен для выгрузки
- [x] **Остатки** — по выбранным складам

### Фильтры (опционально)

Можно настроить выгрузку только части каталога:
- По группам товаров
- По складам
- По видам номенклатуры

### Удаление товаров, скрытых в 1С

Товар с признаком «Не выгружать на сайт» просто исчезает из выгрузки. Чтобы он
исчез и с сайта, в курьерской админке в карточке интеграции «1С: <магазин>»
включите чекбокс **«Удалять товары, не попавшие в полную выгрузку 1С»**.

Как это работает:
1. 1С выгружает каталог целиком (несколько файлов `import___*.xml`), сайт
   запоминает состав каждого файла.
2. После полной выгрузки 1С шлёт команду `mode=deactivate` (расширение
   протокола 1С-Битрикс, узел обмена отправляет её сам).
3. Сайт объединяет состав выгрузки и мягко удаляет товары магазина, которых
   в ней нет. Удаление уезжает в курьерку и витрину событием `product.deleted`.
4. Как только 1С снова пришлёт товар, он восстанавливается.

Предохранители на стороне сайта (удаление отменяется целиком, шаг попадает в
`exchange_logs` со статусом `error`):
- какой-то файл каталога этой выгрузки ещё в очереди, упал или без записи о составе;
- в выгрузку не попала слишком большая доля каталога
  (`ONEC_DEACTIVATE_MISSING_MAX_SHARE`, по умолчанию 20%): это скорее
  усечённая выгрузка на стороне 1С, чем массовое скрытие товаров.

Аварийный выключатель на весь парсер: `ONEC_DEACTIVATE_MISSING_ENABLED=false`.

Проверить, что 1С шлёт команду: в access.log домена обмена должны быть запросы
`mode=deactivate&<дата>_<время>` после серии `mode=import` файлов каталога.

## Шаг 4: Настройка загрузки заказов

1. В настройках узла найдите **Загрузка заказов**
2. Включите опцию **Загружать заказы с сайта**
3. Настройте:

| Параметр | Рекомендация |
|----------|--------------|
| **Вид операции** | Заказ покупателя |
| **Организация** | Ваша организация |
| **Склад** | Основной склад |
| **Контрагент по умолчанию** | Розничный покупатель (для новых клиентов) |

---

## Шаг 5: Расписание обмена

### Вариант A: Ручной запуск

Нажать кнопку **Выполнить обмен** в узле обмена.

### Вариант B: По расписанию

1. Перейдите в **Администрирование → Регламентные задания**
2. Найдите или создайте задание **Обмен с сайтом**
3. Настройте расписание:

| Операция | Рекомендуемое расписание |
|----------|--------------------------|
| Выгрузка каталога | Каждые 4 часа |
| Выгрузка остатков/цен | Каждые 15-30 минут |
| Загрузка заказов | Каждые 10 минут |

### Пример расписания

```
Выгрузка полного каталога: 02:00, 06:00, 10:00, 14:00, 18:00, 22:00
Выгрузка остатков: каждые 15 минут с 08:00 до 22:00
Загрузка заказов: каждые 10 минут с 08:00 до 23:00
```

## Шаг 6: Тестовый обмен

### Проверка соединения

1. Откройте узел обмена
2. Нажмите **Проверить соединение**
3. Должно появиться сообщение: `Соединение установлено успешно`

### Первая выгрузка

1. Нажмите **Выполнить обмен**
2. Выберите **Выгрузить данные на сайт**
3. Дождитесь завершения
4. Проверьте логи в Laravel: `storage/logs/1c-exchange.log`

### Тест заказов

1. Создайте тестовый заказ на сайте
2. В 1С нажмите **Загрузить данные с сайта**
3. Проверьте создание документа "Заказ покупателя"

## Решение проблем

### Ошибка авторизации

**Симптом:** `Ошибка авторизации` или `401 Unauthorized`

**Решение:**
- Проверьте логин/пароль
- Убедитесь, что URL корректный (с https://)
- Проверьте настройки Basic Auth в Laravel

### Ошибка соединения

**Симптом:** `Не удалось установить соединение`

**Решение:**
- Проверьте доступность сайта из сети 1С
- Проверьте firewall
- Убедитесь, что порты 80/443 открыты

### Ошибка при выгрузке файлов

**Симптом:** `Ошибка при передаче файла`

**Решение:**
- Увеличьте таймаут в настройках
- Уменьшите размер порции файла
- Проверьте `upload_max_filesize` и `post_max_size` в PHP

### Товары не появляются на сайте

**Симптом:** Обмен успешен, но данных нет

**Решение:**
- Проверьте очередь Laravel (`php artisan queue:work`)
- Посмотрите логи `storage/logs/1c-exchange.log`
- Проверьте наличие записей в таблице `exchange_logs`

## Дополнительные настройки

### Сжатие файлов

В настройках узла:
- **Сжатие:** Да (использовать ZIP)
- Уменьшает объём передаваемых данных

### Частичная выгрузка

Для оптимизации:
- **Выгружать только изменения** — выгружает только изменённые товары
- Уменьшает время обмена

### Логирование

В 1С можно включить детальное логирование:
- **Администрирование → Настройка обмена → Вести журнал обмена**
- Журнал сохраняется в справочнике "Журнал регистрации"

3. Сверьте версии протокола CommerceML
